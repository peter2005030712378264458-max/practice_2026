IT Stalker Local — practice_2026
================================

Условие: it-stalker-local.exe уже лежит в корне этой папки.
Обычные BAT-файлы из launchers запускают именно его.

Что нужно после скачивания/копирования папки
--------------------------------------------

1. Проверить exe-файл:
   it-stalker-local.exe должен лежать в корне practice_2026.

2. Восстановить runtime-зависимости Node.js:
   запусти GET-DEPS.bat.

   Скрипт выполняет в resources\app:
   npm ci --omit=dev --no-audit

   Если package-lock.json отсутствует, будет использован:
   npm install --omit=dev --no-audit

3. Положить LLM-модели в:
   resources\llm

4. Положить Whisper-модели в:
   resources\whisper

5. Запустить нужный BAT-файл из папки launchers.

Рекомендованный запуск GPU:
launchers\01_recommended\GPU_Qwen3_WhisperMedium.bat
или для более лёгкого Whisper:
launchers\01_recommended\GPU_Qwen3_WhisperSmall.bat

Рекомендованный запуск CPU:
launchers\01_recommended\CPU_Qwen25_WhisperMedium.bat
или для более лёгкого Whisper:
launchers\01_recommended\CPU_Qwen25_WhisperSmall.bat

Модели LLM лежат в resources\llm.
Модели Whisper лежат в resources\whisper.
Лог запуска: it-stalker-debug.log.

Важно: Whisper GPU отключён во всех BAT-файлах. CUDA-варианты означают, что LLM запускается на NVIDIA GPU, а Whisper остаётся на CPU.
