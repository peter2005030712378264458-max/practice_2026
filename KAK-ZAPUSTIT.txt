IT Stalker Local — practice_2026
================================

Эта папка содержит portable-версию приложения. После скачивания с GitHub часть тяжелых файлов нужно восстановить вручную: exe, node_modules, LLM/Whisper/TTS-модели и Python-окружение TTS.

Что НЕ хранится в GitHub
------------------------

- it-stalker-local.exe
- resources\app\node_modules
- resources\llm\*.gguf
- resources\whisper\*.bin
- resources\tts\venv
- resources\tts\models
- resources\tts\output

Обычный запуск без TTS
----------------------

Если аудиоответы не нужны, Qwen3-TTS можно не устанавливать. Обычные BAT-файлы работают по старой цепочке:

Whisper -> LLM -> текстовый ответ

Примеры:

launchers\01_recommended\GPU_Qwen3_WhisperSmall.bat
launchers\01_recommended\GPU_Qwen3_WhisperMedium.bat
launchers\01_recommended\CPU_Qwen25_WhisperSmall.bat
launchers\01_recommended\CPU_Qwen25_WhisperMedium.bat

TTS включается только в отдельном BAT-файле:

launchers\01_recommended\GPU_Qwen3_WhisperSmall_TTS.bat

Развертывание после скачивания с GitHub
---------------------------------------

1. Положить exe-файл в корень проекта:

   practice_2026\it-stalker-local.exe

2. Восстановить Node-зависимости:

   GET-DEPS.bat

   Скрипт устанавливает зависимости в:

   resources\app\node_modules

3. Положить LLM-модели в:

   resources\llm

   Для рекомендуемого GPU-запуска нужна модель:

   Qwen3-4B-Instruct-2507-Q4_K_M.gguf

   Для CPU Qwen2.5 launcher'ов нужна:

   Qwen2.5-3B-Instruct-Q4_K_M.gguf

4. Положить Whisper-модели в:

   resources\whisper

   Минимально для рекомендуемого запуска:

   ggml-small.bin

   Дополнительно, если нужны medium-варианты и VAD:

   ggml-medium.bin
   ggml-silero-v6.2.0.bin

5. Запустить нужный BAT-файл из launchers.

Рекомендуемый запуск с аудиоответами
------------------------------------

Для полной цепочки:

Whisper -> LLM -> текстовый ответ -> Qwen3-TTS -> аудиоответ

используй:

launchers\01_recommended\GPU_Qwen3_WhisperSmall_TTS.bat

Этот BAT включает:

- LLM: Qwen3 4B Instruct через CUDA;
- Whisper: small на CPU;
- TTS: Qwen3-TTS-12Hz-0.6B-CustomVoice на GPU;
- TTS server mode: модель Qwen3-TTS загружается один раз и остается в памяти.

Ключевые переменные в BAT:

set IT_STALKER_TTS_ENABLED=1
set IT_STALKER_TTS_MODEL=%APP_DIR%\resources\tts\models\Qwen3-TTS-12Hz-0.6B-CustomVoice
set IT_STALKER_TTS_SPEAKER=Ryan
set IT_STALKER_TTS_LANGUAGE=Russian
set IT_STALKER_TTS_MAX_CHARS=500
set IT_STALKER_TTS_DEVICE=cuda:0
set IT_STALKER_TTS_SERVER=1

Установка Qwen3-TTS локально
----------------------------

Нужен Python 3.12.

Открой cmd или PowerShell:

cd /d C:\path\to\practice_2026\resources\tts
py -3.12 -m venv venv
venv\Scripts\python -m pip install -U pip
venv\Scripts\pip install -U qwen-tts soundfile "huggingface_hub[cli]"
venv\Scripts\pip install --upgrade --force-reinstall torch==2.11.0+cu126 torchaudio==2.11.0+cu126 --index-url https://download.pytorch.org/whl/cu126
venv\Scripts\huggingface-cli download Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice --local-dir models\Qwen3-TTS-12Hz-0.6B-CustomVoice

Проверка GPU для TTS:

venv\Scripts\python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.version.cuda); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"

Ожидаемый результат для GPU-режима:

2.11.0+cu126
True
12.6
NVIDIA GeForce RTX 3060

Проверенная конфигурация TTS
----------------------------

- qwen-tts: 0.1.1
- torch: 2.11.0+cu126
- torchaudio: 2.11.0+cu126
- TTS model: Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice
- device: cuda:0
- server mode: enabled

Важно: первый запуск TTS может быть медленнее, потому что модель загружается в VRAM. Последующие аудиоответы быстрее, так как qwen3-tts-server.py держит модель загруженной.

Голоса Qwen3-TTS
----------------

В BAT по умолчанию стоит:

set IT_STALKER_TTS_SPEAKER=Ryan

Доступные голоса CustomVoice модели:

Ryan, Aiden, Vivian, Serena, Uncle_Fu, Dylan, Eric, Ono_Anna, Sohee

Чтобы сменить голос, поменяй IT_STALKER_TTS_SPEAKER в BAT.

Где сохраняются аудиоответы
---------------------------

WAV-файлы TTS сохраняются в:

resources\tts\output

После успешной генерации в логе будет строка вида:

TTS: audio ready (...resources\tts\output\....wav)
TTS: playback started

Логи
----

Основной лог приложения:

it-stalker-debug.log

Для успешного TTS GPU запуска в логе должны быть строки:

Model preset: gpu-small
LLM local: Qwen готова (cuda)
TTS server: starting (cuda:0)
TTS server: ready (cuda:0)
TTS: synthesis started (... chars)
TTS: audio ready (...wav)
TTS: playback started

Если запущен обычный launcher без TTS
-------------------------------------

Приложение работает без resources\tts\venv и без TTS-модели. В этом режиме аудиоответов нет, но Whisper -> LLM -> текстовый ответ работает как раньше.
